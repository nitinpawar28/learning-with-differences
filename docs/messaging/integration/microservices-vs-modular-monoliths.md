# Microservices vs. Modular Monoliths

!!! note "Status"
    Draft stub — expand using the [article template](../../about/article-template.md).

## Scope

Compare choices such as:

- Independent deployability (microservices) vs. simpler operations (modular monolith)
- Team/org boundaries as a driver for service boundaries (Conway's Law)
- Distributed transactions/sagas vs. in-process transactions
- Shared database vs. database-per-service
- Migration path: modular monolith as a stepping stone to microservices
