## Why this is catalogue only

DP-300 is active as of 2026-10-24. The [certification page](https://learn.microsoft.com/en-us/credentials/certifications/azure-database-administrator-associate/) lists a 100-minute proctored exam with renewal every 12 months, and it announces that the English version will be updated on October 27, 2026. The [study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-300) already shows the new outline:

| Skill area | Weight |
| --- | --- |
| Plan and implement data platform resources | 15–20% |
| Implement a secure environment | 20–25% |
| Monitor, configure, and optimize database resources | 20–25% |
| Configure and manage automation of tasks | 15–20% |
| Plan and configure a high availability and disaster recovery (HA/DR) environment | 20–25% |

It is a database administrator exam for Azure SQL Database, Azure SQL Managed Instance and SQL Server on Azure VMs. It covers migration planning, authentication and encryption, query-performance monitoring, SQL Server Agent jobs, automated deployment, backup and restore, and HA/DR configuration. Your target roles need to choose between Azure SQL deployment options and design for availability, which AZ-305 covers. Running databases day to day is not on your path.

## Differences from related exams

- **DP-300 vs DP-800.** Both exams cover the same SQL platforms. DP-300 is the administrator who keeps databases available, secure and fast. DP-800 is the developer who writes the schema, T-SQL, deployment pipelines and AI features.
- **DP-300 vs AZ-305.** AZ-305 decides which data service and which availability approach a design needs. DP-300 configures, monitors and recovers the result.
- **DP-300 vs AWS.** AWS retired its Database – Specialty in April 2024, so there is no current AWS counterpart.
