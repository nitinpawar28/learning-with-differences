## Why this is catalogue only

DP-750 is active as of 2026-10-24 and leads to Microsoft Certified: Azure Databricks Data Engineer Associate. The [certification page](https://learn.microsoft.com/en-us/credentials/certifications/implementing-data-engineering-solutions-using-azure-databricks/) lists a 120-minute proctored exam, and the [study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-750) shows skills measured as of October 19, 2026. It is skipped for the same reason as DP-700: it is a hands-on data engineering exam.

- **Environment setup (15–20%):** configuring compute and creating Unity Catalog objects.
- **Unity Catalog security and governance (15–20%):** privileges, row filters and column masks, attribute-based access control, lineage, audit logging and Delta Sharing.
- **Preparing and processing data (30–35%):** ingestion with Lakeflow Connect, Auto Loader and Spark Structured Streaming, data modelling, cleansing and data-quality expectations.
- **Deploying and maintaining pipelines (30–35%):** Lakeflow Jobs, Declarative Automation Bundles deployed with the Databricks CLI, Git workflows and Spark performance troubleshooting.

Your roadmap needs the lakehouse concepts, not operational Databricks skills.

## Differences from related exams

- **DP-750 vs DP-700.** Both test the data engineer role. DP-750 is lakehouse engineering on Azure Databricks with Unity Catalog governance. DP-700 uses Microsoft Fabric's SaaS workspace model. The DP-750 audience is also expected to know the Azure services around the workspace: Microsoft Entra, Azure Data Factory and Azure Monitor.
- **DP-750 vs DEA-C01 (AWS Data Engineer – Associate).** DEA-C01 tests the AWS-native data services rather than a single lakehouse platform. DP-750's troubleshooting skills go further into Spark internals, such as skew, spill and shuffle, read through the Spark UI and query profile.
- **DP-750 vs Databricks' own certifications.** Databricks runs its own vendor certifications, which this library does not track. DP-750 is Microsoft's view of the platform and includes the Azure integration points.
