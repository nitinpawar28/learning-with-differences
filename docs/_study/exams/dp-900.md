## Why this is catalogue only

DP-900 is active as of 2026-10-24. The [certification page](https://learn.microsoft.com/en-us/credentials/certifications/azure-data-fundamentals/) lists a 45-minute proctored exam in 13 languages, and the [study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-900) shows skills measured as of July 21, 2026. Like other Microsoft fundamentals certifications, it does not expire. It is skipped because it repeats ground you have already covered. AZ-900 introduced the Azure data services, and the concepts DP-900 tests are covered in more depth in this library's data section and in the associate exams. Those concepts are ways of representing data, relational and non-relational workloads, transactional and analytical workloads, Cosmos DB capabilities, large-scale and real-time analytics, and Power BI basics. Microsoft states that DP-900 is not a prerequisite for any role-based certification. Spend the time on an associate exam instead.

## Differences from related exams

- **DP-900 vs AZ-900.** Both are fundamentals exams. AZ-900 is about cloud concepts and Azure as a platform. DP-900 is about data workloads: relational or non-relational, transactional or analytical, and which Azure data service fits each.
- **DP-900 vs DP-300, DP-700 and DP-600.** The associate exams replace DP-900's "describe" verbs with "implement" and "optimize". DP-300 administers Azure SQL, DP-700 builds Microsoft Fabric pipelines and DP-600 builds semantic models.
- **DP-900 vs AWS.** AWS has no data fundamentals exam. The nearest is CLF-C02 (Cloud Practitioner), which covers data services only briefly.
