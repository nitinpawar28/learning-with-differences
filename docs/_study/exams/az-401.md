## What the exam really tests

AZ-401 keeps AZ-400's job (designing and delivering DevOps on Azure DevOps and GitHub) and adds the assumption that you do much of that work *with* AI agents. The audience profile asks for practical YAML, KQL and Bicep and for experience with "Microsoft and GitHub AI tools".

- **Processes and communications (15–20%).** Flow of work across plan, build, deploy and operate. Feedback cycles. Azure Boards tracking and traceability. Turning business KPIs into DevOps success metrics and querying them with AI-assisted tools. AI-assisted documentation (readmes, change logs, licences, CODEOWNERS, diagrams). New for agents: **specifying requirements and restrictions for agentic development (agents, skills and loops)**, configuring the **Azure DevOps MCP server and GitHub MCP server**, integrating through webhooks, MCP servers and skills, and linking Boards to GitHub through MCP.
- **Source control (10–15%).** Trunk-based, feature, release, Git flow, GitHub flow and **Git worktrees** (which agents use to work in parallel). Pull request workflows. **Branch protection for GitHub Copilot** (for example the rules that govern Copilot coding agent pull requests). Git hooks for automatic checks. Traceability that links code quality and coverage to work items. Migrating repositories from Azure DevOps to GitHub.
- **Build and release (35–40%).** The AZ-400 core: package feeds and versioning, testing strategy and gates, YAML pipelines, triggers, templates, environments, runner and agent infrastructure, deployment patterns, IaC and configuration management, and pipeline maintenance. Gates, tests and coverage are now implemented **by using GitHub Copilot and MCP servers**, pipelines are written in YAML *by using GitHub Copilot*, and there is a new bullet for **GitHub Agentic Workflows**.
- **Security and compliance (15–20%).** Service principals versus managed identities, GitHub Apps, GITHUB_TOKEN and PATs, secretless authentication, service connections, permissions and access levels, Key Vault in both platforms, secure files and GitHub secrets, preventing leakage, GitHub Advanced Security on both platforms, and Defender for Cloud DevOps security across environments.
- **Instrumentation (15–20%).** Flow dashboards, Azure Monitor and Log Analytics integration, GitHub insights, pipeline alerts. Then **AI agents for operations: deploy and configure the Azure Copilot Observability Agent and the Azure SRE Agent, and investigate and resolve issues the SRE Agent raises**. Analysis is done with AI agents, including Copilot agent logs and natural-language or basic KQL queries.

Where candidates are likely to lose points: treating "use Copilot" as the answer to everything. The exam still tests the underlying control (a branch protection rule, a gate, a secretless identity), and the AI tool is the way you implement it. Also expect confusion between MCP servers, skills and agents, and between the observability and SRE agents' responsibilities, plus the usual GitHub-versus-Azure DevOps naming traps.

## Study strategy

1. **Foundations first.** Learn the AZ-400 material (see that page), because the classic DevOps skills still make up most of this outline. Earn AZ-104, which is on your path anyway and counts as one of the prerequisite options.
2. **Agent tooling.** Use GitHub Copilot in VS Code and on GitHub with a custom instructions file, try the Copilot coding agent on an issue, and look at the protection rules that apply to its pull requests. Connect the GitHub MCP server and the Azure DevOps MCP server to an agent and use them to query work items and pipeline runs.
3. **Agentic workflows.** Write a GitHub Agentic Workflow alongside a normal Actions workflow so you can see what is different: what triggers it, what permissions it gets, and how its output is reviewed.
4. **Operations agents.** Deploy the Azure SRE Agent against a small App Service or Container Apps workload with Application Insights, cause a fault, and follow the agent's investigation. Compare it with what the Azure Copilot Observability Agent shows.
5. **Write things down.** Practise expressing requirements and restrictions for agents (what they may change, which tools they may call, when a human must approve). This is a design skill the outline names explicitly.

Official resources as of 2026-10-24: the beta study guide (its documentation list covers the DevOps resource centre, Azure DevOps, Azure Boards, Key Vault, Azure Monitor, Azure Pipelines, Azure Repos, *Work with Azure DevOps and GitHub*, authenticating with a GitHub App, GitHub Advanced Security for Azure DevOps, GitHub Actions, GitHub Advanced Security and GitHub Copilot), the exam sandbox, and the AZ-400 learning content. Microsoft has not yet published AZ-401 learning paths.

How your background helps or misleads:

- **Agentic AI goals.** This exam sits at the meeting point of your DevOps and agentic AI tracks. MCP, skills and agent loops are ideas you will also meet in the Anthropic and AI-architect exams, but here they are tested through Microsoft and GitHub products.
- **AZ-204 preparation** helps with Application Insights and identity. **CKAD preparation** helps with container deployment.
- **.NET and Angular background** gives you a realistic codebase to practise agent-written tests and pipelines on.
- **Caution.** A beta outline changes, and the product names here are new and still moving (Azure SRE Agent, Azure Copilot agents, GitHub Agentic Workflows). Check the current documentation names before the exam.

## Differences from related exams

- **AZ-401 vs AZ-400.** The domains and much of the wording are the same, but the weights move. Build and release drops from 50–55% to 35–40%, while processes rise to 15–20%, security to 15–20% and instrumentation to 15–20%. AZ-401 adds MCP servers, agent requirements, Copilot branch rules, Git worktrees and hooks, ADO-to-GitHub migration, GitHub Agentic Workflows and operations agents. It drops Scalar, git-fat, Azure Deployment Environments, Azure Automation State Configuration and Azure Machine Configuration, and classic-to-YAML migration. AZ-400's prerequisite was an associate certification (AZ-104 or AZ-204). AZ-401's announced prerequisite is AZ-104 *or* GH-300.
- **AZ-401 vs DOP-C02 (AWS Certified DevOps Engineer – Professional).** DOP-C02 has no agentic content and focuses on running and recovering AWS workloads with AWS-native tooling. AZ-401 covers process, two tool platforms and AI-assisted delivery and operations.
- **AZ-401 vs GH-300 (GitHub Copilot).** GH-300 tests Copilot features, plans and responsible use. AZ-401 tests Copilot and MCP as parts of a delivery system, with governance around them.

## Exam-day notes

- Beta exams have rough edges. Use the comment box on questions you think are ambiguous. The about beta exams page says Microsoft reads and evaluates every beta comment before final scoring.
- Pace yourself to finish rather than polishing early answers. With no practice assessment yet, the first questions are where you calibrate, so don't spend too long on them.
- For any "by using GitHub Copilot or MCP" bullet, first identify the control or artefact the scenario needs, then the agent mechanism that produces it.
- Results will not appear at the end of the session. They come after general availability.
