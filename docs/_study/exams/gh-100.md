## Why this is catalogue only

GitHub Administration (GH-100) is active as of 2026-10-24. The [certification page](https://learn.microsoft.com/en-us/credentials/certifications/github-administration/) lists an intermediate-level, proctored, 100-minute exam, delivered through Pearson VUE, in English only. Its five domains are identities and access (15–20%), the enterprise environment (10–15%), secure software development and compliance (25–30%), GitHub Actions (20–25%), and monitoring and optimizing usage (10–15%). GitHub certifications are valid for 2 years, and the page says GitHub is moving to Microsoft's renewal process.

It is catalogue-only because it is written for people who run a GitHub Enterprise account: enterprise and organization policies, SSO and SCIM provisioning, Enterprise Managed Users, runner fleets, billing and audit logs. An architect or security engineer needs to know these controls exist, but rarely administers them day to day. GH-200 (Actions) and GH-500 (Advanced Security) give the target roles more value per hour of study.

## Differences from related exams

- **GH-100 vs GH-900.** GH-900 is the broad, shallow user view of GitHub. GH-100 is the owner's view of a whole enterprise: who gets in, which policies apply to every organization, and how usage is audited and billed.
- **GH-100 vs GH-200 and GH-500.** All three touch Actions and Advanced Security. GH-200 tests writing and debugging workflows, and GH-500 tests configuring and triaging code, secret and dependency scanning. GH-100 tests governing them at enterprise scale, for example runner groups, allowed-actions policies and enabling security features across organizations.
- **GH-100 vs AZ-104.** Both are administrator exams about identity, policy and monitoring. AZ-104 applies them to Azure resources and GH-100 to the source-control platform. Entra ID knowledge from AZ-104 carries over to GH-100's SSO and provisioning topics.
