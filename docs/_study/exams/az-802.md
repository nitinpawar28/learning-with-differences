## Why this is catalogue only

AZ-802 (Administering Windows Server) is active as of 2026-10-24. It is the single exam for **Microsoft Certified: Windows Server Administrator Associate**. The [certification page](https://learn.microsoft.com/en-us/credentials/certifications/windows-server-hybrid-administrator/) lists 120 minutes, English only, with renewal on Microsoft Learn. It replaces the former two-exam route, AZ-800 plus AZ-801 for the Windows Server Hybrid Administrator Associate. Microsoft's [retirement announcement](https://techcommunity.microsoft.com/blog/skills-hub-blog/the-ai-job-boom-is-here-are-you-ready-to-showcase-your-skills/4494128) lists AZ-802 as the replacement for both, and Microsoft's [earlier certification page](https://learn.microsoft.com/en-us/credentials/certifications/windows-server-administrator-associate/) records that AZ-800 and AZ-801 retired on September 30, 2026.

The [exam page](https://learn.microsoft.com/en-us/credentials/certifications/exams/az-802/) shows seven skill areas, led by AD DS (20–25%). The others are hybrid management with Windows Admin Center and Azure Arc, Hyper-V and Azure VMs, on-premises and hybrid networking, storage and file services including Azure Files, Windows Server security, and monitoring and troubleshooting. That is an infrastructure administrator's role. Running Windows Server estates is not on your path, and the hybrid pieces that matter (Azure Arc, Azure Monitor, Azure Update Manager, Defender for Cloud, Azure Files) come up in AZ-104, AZ-305 and SC-500.

## Differences from related exams

- **AZ-802 vs AZ-800 and AZ-801.** It is one exam instead of two. High availability, disaster recovery and server migration each had a domain of their own in AZ-801. They are not separate skill areas in AZ-802.
- **AZ-802 vs AZ-104.** AZ-104 administers Azure resources. AZ-802 administers the Windows Server operating system wherever it runs, whether on-premises, in Azure or in a hybrid environment, and uses Azure services as management tools.
- **AZ-802 vs AWS.** AWS has no Windows Server administration certification, so there is no counterpart.
