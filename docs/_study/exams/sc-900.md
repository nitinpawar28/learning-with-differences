## What the exam really tests

SC-900 is a vocabulary-and-positioning exam. Every bullet in the outline starts with "Describe" or "Define". You will not configure anything. You are asked to recognise which Microsoft product solves a stated problem and to know the concept behind it. The four areas are weighted so that **Microsoft security solutions (35–40%)** dominates, followed by **Microsoft Entra (25–30%)**, **compliance with Microsoft Purview (20–25%)** and **concepts (10–15%)**.

Typical scenarios are short: "An organisation wants to require MFA only when a sign-in comes from outside the corporate network. Which feature?" (Conditional Access, not Security Defaults). Or "Which service gives a secure-score style measure of regulatory compliance?" (Compliance Manager and compliance score, not Defender for Cloud secure score).

Candidates lose points in four predictable places:

- **Look-alike products.** Defender for Cloud (Azure and multicloud workload posture) versus Defender XDR (the Microsoft 365 family of Endpoint, Office 365, Identity and Cloud Apps), Microsoft Sentinel (SIEM and SOAR) versus Defender XDR (XDR), and Azure Firewall versus Azure WAF versus NSGs.
- **Purview vocabulary.** Sensitivity labels classify and protect content; retention labels keep or delete it. Records management is retention with immutability. DLP stops sharing; insider risk management detects risky user behaviour. eDiscovery finds content for legal cases; Audit records activities.
- **Entra governance terms.** PIM gives just-in-time role activation, access reviews recertify membership, entitlement management bundles access packages, and ID Protection scores user and sign-in risk.
- **Concept questions** that sound obvious but hinge on wording: hashing is one-way while encryption is reversible; authentication proves who you are while authorisation decides what you may do; federation trusts another identity provider.

## Study strategy

1. **Concepts first (domain 1).** Shared responsibility, defence in depth, Zero Trust (verify explicitly, use least privilege, assume breach), encryption versus hashing, and GRC. This is the smallest domain, but it is the language the other three use.
2. **Microsoft Entra (domain 2).** Map identity types: users, guests, groups, devices, and workload identities (service principals and managed identities). Then hybrid identity (Entra Connect / Cloud Sync, password hash sync, pass-through authentication, federation), authentication methods, Conditional Access, Entra roles versus Azure RBAC, and the governance features.
3. **Security solutions (domain 3).** Work outward from the network (DDoS Protection, Azure Firewall, WAF, NSGs, Bastion, Key Vault) to posture (Defender for Cloud, CSPM, workload protection), then SIEM/SOAR (Sentinel) and XDR (each Defender product and the Defender portal).
4. **Compliance (domain 4).** Service Trust Portal and Microsoft's privacy principles, the Purview portal, Compliance Manager, then classification, labels, DLP, retention, records, insider risk, eDiscovery and Audit.

Hands-on work is optional but cheap and effective. A free Microsoft 365 developer or trial tenant plus an Azure free account lets you click through the Entra admin center, the Defender portal and the Purview portal, so the product names stick to a picture.

Official resources: the self-paced SC-900 learning paths and the instructor-led course linked from the [certification page](https://learn.microsoft.com/en-us/credentials/certifications/security-compliance-and-identity-fundamentals/), the free practice assessment, the exam sandbox, the Exam Readiness Zone videos, and the documentation the [study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/sc-900) lists (Microsoft security, Azure security, Entra ID, Sentinel, Defender and Purview docs, and the Service Trust Portal introduction).

How your background helps or misleads:

- **AZ-900** already gave you shared responsibility, defence in depth, NSGs, Key Vault and Azure RBAC. Roughly a fifth of SC-900 will feel familiar. The new ground is Microsoft 365 security and Purview, which AZ-900 never touches.
- **AZ-204 prep** taught app registrations, managed identities, MSAL tokens and Key Vault from a developer's side. That makes workload identities and authentication methods easy. But SC-900 asks what a feature is for, not how to call it, so do not over-think the protocol.
- **CKAD prep** helps little directly; container security is not on SC-900.
- **Basic AWS knowledge** can mislead. IAM in AWS mixes identity and permissions in one service. Microsoft splits it into Entra ID (identity and directory roles) and Azure RBAC (resource permissions), and the exam tests that split.

## Differences from related exams

- **SC-900 vs AZ-900.** AZ-900 surveys all of Azure (compute, networking, storage, pricing, governance) with security as one slice. SC-900 goes deeper into that slice and adds Microsoft 365 security and compliance. Both are "describe" exams of similar difficulty; SC-900 has a denser product list.
- **SC-900 vs CLF-C02 (AWS Certified Cloud Practitioner).** The closest AWS exam. Cloud Practitioner gives security and compliance one domain among four and stays inside AWS (IAM, Shield, WAF, GuardDuty, Artifact). AWS has no separate security fundamentals exam. SC-900 covers identity governance and data compliance in a breadth no AWS foundational exam attempts; Purview has no single AWS equivalent.
- **SC-900 vs SY0-801 (CompTIA Security+ V8).** As of 2026-10-24, CompTIA says V8 is expected to launch on or around November 17, 2026; until then, V7 (SY0-701) is the live exam. Security+ is vendor-neutral and much deeper on threats, cryptography, network attacks and incident response. SC-900 is shallower but product-specific. Security+ helps you understand why; SC-900 tells you which Microsoft product does it.
- **SC-900 vs the associate SC exams.** Each SC-900 domain is the trailer for an associate exam: Entra leads to SC-300, the Defender and Sentinel material to SC-200, Purview to SC-401, and Azure infrastructure security to SC-500. SC-900 is not a prerequisite for any of them, but it is the map for all of them.

## Exam-day notes

- 45 minutes is usually ample. Aim to finish a first pass by minute 30 and use the rest for flagged items.
- Read the product name in every answer option carefully. Distractors are often a real product in the wrong family (Defender for Cloud Apps offered where Defender for Cloud is meant, or Compliance Manager where Compliance score is meant).
- For statement sets ("Yes/No for each of three statements") and other multi-part questions, Microsoft's [scoring page](https://learn.microsoft.com/en-us/credentials/certifications/exam-scoring-reports) says you usually earn one point for each correct component, so treat each statement on its own. There is no penalty for a wrong answer, so never leave an item blank.
- "Which feature should you use" questions usually have one answer that is technically possible and another that is the purpose-built feature. Pick the purpose-built feature.
- Product names change often (Azure AD became Microsoft Entra ID, Microsoft 365 Defender became Defender XDR). Expect current names on the exam, and do not be thrown by older names in older study material.
