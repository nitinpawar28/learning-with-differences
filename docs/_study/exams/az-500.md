## Why this is catalogue only

As of 2026-10-24 AZ-500 is retired. The [certification page](https://learn.microsoft.com/en-us/credentials/certifications/azure-security-engineer/) says the certification, the exam and the renewal assessments were retired on August 31, 2026, and that the certification can no longer be earned or renewed. The [study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-500) gives the cut-off as 11:59 PM Central Standard Time. Microsoft's [retirement announcement](https://techcommunity.microsoft.com/blog/skills-hub-blog/the-ai-job-boom-is-here-are-you-ready-to-showcase-your-skills/4494128) names **Cloud and AI Security Engineer Associate (Exam SC-500)** as the replacement.

The security track in this library therefore runs through [SC-500](https://learn.microsoft.com/en-us/credentials/certifications/cloud-and-ai-security-engineer-associate/), whose exam is titled Implementing End-to-End Security Controls for Cloud and AI Workloads. The last AZ-500 outline (skills measured as of January 22, 2026) is linked above only as a historical reference.

## Differences from related exams

- **AZ-500 vs SC-500.** The two outlines overlap heavily. Both cover Microsoft Entra ID controls (PIM, Conditional Access, app registrations and consent, managed identities), Key Vault, network security (NSGs, ASGs, Azure Virtual Network Manager, private endpoints, Azure Firewall), storage and Azure SQL security, Defender for Cloud and Microsoft Sentinel data collection. The [SC-500 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/sc-500) adds a whole "Implement security for AI" skill group. That group covers protecting Copilot Studio agents, Microsoft Entra Agent ID, the AI gateway in API Management for Microsoft Foundry, Defender for AI services and Purview DSPM. SC-500 also adds Microsoft Security Copilot, Microsoft Entra Private Access and security controls through Azure Policy and infrastructure as code, and it expects some Microsoft 365 administration knowledge. AZ-500 gave Defender for Cloud and Sentinel 30–35% of the exam. SC-500 spreads its four areas evenly, at 20–30% each.
- **AZ-500 vs SCS-C03 (AWS Certified Security – Specialty).** Both test hands-on platform security, but the AWS exam is specialty-level and entirely AWS-native, with controls such as IAM policies, AWS KMS, Amazon GuardDuty and AWS Security Hub. AZ-500 mixed identity, network and SIEM tooling from several Microsoft product families.
- **AZ-500 vs SC-200 and SC-100.** SC-200 is the security operations analyst exam: investigation and hunting in Defender XDR and Sentinel. SC-100 is the expert architect exam, which designs the overall security strategy. AZ-500 sat between them, as the engineer who implements the controls. SC-500 now fills that role.
