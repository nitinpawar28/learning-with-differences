## Why this is catalogue only

DP-800 is active as of 2026-10-24 and leads to Microsoft Certified: SQL AI Developer Associate. The [certification page](https://learn.microsoft.com/en-us/credentials/certifications/developing-ai-enabled-database-solutions/) lists a 120-minute proctored exam, and the [study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-800) shows skills measured as of October 19, 2026. It covers SQL Server, Azure SQL and SQL databases in Microsoft Fabric.

The AI part is a quarter of the exam (25–30%). It covers external models and embeddings, the vector data type and vector indexes, `VECTOR_DISTANCE` and `VECTOR_SEARCH`, hybrid search with reciprocal rank fusion, and RAG through `sp_invoke_external_rest_endpoint`. The other 70–80% is a T-SQL developer exam:

- specialised tables (temporal, ledger, graph, in-memory)
- views, functions, procedures and triggers
- advanced T-SQL, including window, JSON, regular-expression and fuzzy-matching functions
- Always Encrypted, Dynamic Data Masking and row-level security
- query tuning with Query Store and DMVs
- CI/CD with SQL Database Projects
- Data API builder for REST and GraphQL endpoints
- GitHub Copilot, Copilot in Fabric and MCP tools for AI-assisted SQL development

It is a skip for you because the vector search and RAG ideas are taught in this library's AI section and are tested more directly by AI-200 and AI-103. DP-800 makes sense for someone who writes T-SQL for a living.

## Differences from related exams

- **DP-800 vs DP-300.** DP-300 is the administrator exam: deployment, HA/DR, backup, automation and monitoring. DP-800 is the developer exam: schema, T-SQL, CI/CD, APIs and AI features. They share security and performance topics, approached from opposite ends.
- **DP-800 vs DP-420.** Both are database developer exams with an AI angle. DP-420 targets Azure Cosmos DB. DP-800 targets the SQL family.
- **DP-800 vs AWS.** AWS retired its Database – Specialty in April 2024, so there is no AWS counterpart.
