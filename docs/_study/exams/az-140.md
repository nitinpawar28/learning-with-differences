## Why this is catalogue only

AZ-140 is active as of 2026-10-24. The [certification page](https://learn.microsoft.com/en-us/credentials/certifications/azure-virtual-desktop-specialty/) lists a 100-minute proctored exam with renewal every 12 months, and the [study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-140) shows skills measured as of July 20, 2026. It stays in the catalogue because it is a single-workload specialty for server and desktop administrators. The largest share (40–45%) is building the Azure Virtual Desktop platform itself: network design with RDP Shortpath, FSLogix storage on Azure Files or Azure NetApp Files, host pools and session hosts, licensing, and session-host images built with Azure VM Image Builder and stored in Azure Compute Gallery. Next comes user environments and apps (20–25%): FSLogix profile containers, clients and redirection, RemoteApp, App attach, and Microsoft 365 Apps and Teams on multi-session hosts.

None of this moves your architect, agentic-AI, security or multi-cloud goals forward, and AWS has no certification for its desktop service to compare against. The general skills AZ-140 builds on, such as identity, networking, storage, VM sizing, Conditional Access and Defender for Cloud, are covered more usefully by AZ-104, AZ-305 and SC-500.

## Differences from related exams

- **AZ-140 vs AZ-104.** AZ-104 is broad platform administration. AZ-140 assumes that knowledge and goes deep on one workload, so its scenarios are about session-host density, profile storage, images and client experience rather than subscriptions and virtual networks in general.
- **AZ-140 vs AZ-305.** AZ-305 might ask whether virtual desktops belong in a design at all. AZ-140 asks how to size, image, secure, scale, back up and recover them once they do.
- **AZ-140 vs AWS.** AWS offers no end-user computing certification, so there is no counterpart.
