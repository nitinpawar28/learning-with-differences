## Why this is catalogue only

GitHub Foundations (GH-900) is active as of 2026-10-24. The [certification page](https://learn.microsoft.com/en-us/credentials/certifications/github-foundations/) lists a 100-minute proctored exam, delivered through Pearson VUE, in English, Spanish, Portuguese (Brazil), Korean and Japanese. The [study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-900) shows skills at a glance as of January 2026. The certification page also says GH-900 does not require renewal, because it follows Microsoft's policy for fundamentals-level exams.

It is catalogue-only because a working .NET and Angular developer already uses most of what it tests. That includes Git and GitHub basics (the largest area, 25–30%), repositories, pull-request collaboration, Projects, introductory Actions and Copilot, privacy and security settings, and the open-source community. If you want a GitHub credential, GH-200 (Actions), GH-300 (Copilot) and GH-500 (Advanced Security) test skills the target roles actually use.

## Differences from related exams

- **GH-900 vs AZ-900.** Both are fundamentals exams that do not expire. AZ-900 tests cloud concepts. GH-900 tests the collaboration platform and the Git model underneath it.
- **GH-900 vs GH-100, GH-200, GH-300 and GH-500.** GH-900 is broad and shallow. Each of the others takes one slice to intermediate depth: enterprise administration (GH-100), workflow automation (GH-200), AI pair programming (GH-300) and supply-chain security (GH-500). The others need renewal, and GH-900 does not.
