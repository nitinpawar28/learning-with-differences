## Why this is catalogue only

DP-700 is active as of 2026-10-24. The [certification page](https://learn.microsoft.com/en-us/credentials/certifications/fabric-data-engineer-associate/) lists a 100-minute proctored exam with renewal on Microsoft Learn, and the [study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-700) shows skills measured as of October 19, 2026. It has three equally weighted areas (30–35% each). The first is implementing and managing an analytics solution: workspace settings, lifecycle management, security and governance, and orchestration. The second is ingesting and transforming batch and streaming data. The third is monitoring and optimising Fabric items. All three assume day-to-day data engineering work in Microsoft Fabric with SQL, PySpark and KQL. Your roadmap needs you to understand data platforms as an architect, not to operate Fabric pipelines, so DP-700 stays in the catalogue.

## Differences from related exams

- **DP-700 vs DP-750.** The role is the same but the platform differs. DP-700 is Microsoft Fabric, a SaaS platform of workspaces and items with built-in lifecycle management. DP-750 is Azure Databricks, with Unity Catalog governance, Lakeflow, Delta tables and Spark tuning.
- **DP-700 vs DP-600.** DP-700 builds and runs the pipelines. DP-600 models the resulting data for analysis.
- **DP-700 vs DEA-C01 (AWS Data Engineer – Associate).** DEA-C01 tests the same role across a set of separate AWS services, such as AWS Glue, Amazon Redshift, Amazon Kinesis and AWS Lake Formation, rather than inside one SaaS platform. Expect more service-selection questions on the AWS exam and more platform-configuration questions on DP-700.
