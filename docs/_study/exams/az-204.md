## Why this is catalogue only

As of 2026-10-24 this exam no longer exists. Microsoft retired AZ-204 on July 31, 2026 at 11:59 PM Central Standard Time (see the warning on the [study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-204)), and the [certification page](https://learn.microsoft.com/en-us/credentials/certifications/azure-developer/) says the Azure Developer Associate certification and its renewal assessment are retired too. Microsoft's [retirement announcement](https://techcommunity.microsoft.com/blog/skills-hub-blog/the-ai-job-boom-is-here-are-you-ready-to-showcase-your-skills/4494128) names **Azure AI Cloud Developer Associate (Exam AI-200)** as the replacement, and tells anyone who is not close to testing to prepare for AI-200 instead. Certifications already earned stay valid until they expire, but they can no longer be renewed.

The last outline (skills measured as of January 14, 2026) is still linked above as a historical reference. The library does not track coverage against it.

Your AZ-204 preparation is not wasted. Building and publishing container images to Azure Container Registry, Azure Container Apps, Azure Functions triggers and bindings, Service Bus, Event Grid, the Cosmos DB SDK and change feed, Key Vault and App Configuration all reappear in the [AI-200 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-200). What is new is Python (named in the AI-200 audience profile; the AZ-204 profile named no language), vector search and retrieval-augmented generation on Cosmos DB, Azure Database for PostgreSQL and Azure Managed Redis, AKS manifests, and troubleshooting with OpenTelemetry and KQL. Take [AI-200](https://learn.microsoft.com/en-us/credentials/certifications/azure-ai-cloud-developer-associate/), not this exam.

## Differences from related exams

- **AZ-204 vs AI-200 (its successor).** AZ-204 covered general Azure application development in five areas: compute (App Service web apps, Functions, containers), storage (Cosmos DB, Blob Storage), security (Microsoft identity platform, Microsoft Entra ID, shared access signatures, Microsoft Graph, Key Vault, managed identities), monitoring with Application Insights, and integration (API Management, Event Grid, Event Hubs, Service Bus, Queue Storage). AI-200 keeps the back-end developer role but builds it around AI workloads. Its four areas are containerized solutions (including AKS and KEDA scaling in Container Apps), AI solutions on Azure data services, connecting services (Service Bus, Event Grid, Functions), and securing and monitoring solutions. API Management, Event Hubs, Queue Storage, Blob Storage operations and the Microsoft identity platform and Microsoft Graph items are not in the AI-200 skills list.
- **AZ-204 vs DVA-C02 and DVA-C03 (AWS Developer – Associate).** These cover the same role at the same level, with SDK-centred scenarios on serverless, messaging, data and security. The AWS exam puts more weight on deployment and CI/CD (DVA-C02: Development with AWS Services 32%, Security 26%, Deployment 24%, Troubleshooting and Optimization 18%). DVA-C02's last day is November 30, 2026, and DVA-C03 delivery starts December 1, 2026.
- **AZ-204 vs AZ-104 and AZ-305.** AZ-104 tests running the platform and AZ-305 tests designing on it. AZ-204 tested writing the code that runs on it.
