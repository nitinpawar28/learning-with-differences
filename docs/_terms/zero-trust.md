## Explanation

A security model that assumes no implicit trust from network location alone
(no "inside the firewall = trusted") — every request is authenticated and
authorized regardless of where it originates. [mTLS](mtls.md) and
[workload identity](workload-identity.md) are two of the building blocks used
to implement it.
